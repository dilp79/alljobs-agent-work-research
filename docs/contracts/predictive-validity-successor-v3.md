# Predictive-validity successor v3

V3 retains the V2 model, transport, provider, case transformations, category balance, vote doses,
budget ceiling, pilot target, main target, analysis, and claim ceiling. The V3 builder fails unless
all 20 pilot and 70 main case IDs, input hashes, and vote vectors are identical and ordered exactly
as in the frozen V2 frame.

## Instrument change justified by V2

V2 proved that schema shape alone omitted required executable serialization semantics. Even
correctly reasoned outputs used unsupported wording, identifier encoding, or list formats and failed
the exact domain checker. V3 therefore adds one different, category-matched development case with
its checker-approved answer. The worked example is neither the pilot target mission nor any main
mission. Its input/output and competence receipts are frozen by hash before calls.

This scaffold intentionally conveys reusable semantic and serialization content, not just format.
Accordingly, V3 measures agent-plus-worked-example deterministic conformance; it cannot isolate
model capability, copying, or a format effect.

## Pilot and stop rule

The same 20 V2 pilot cases run under two frozen arms:

- one category-matched worked example; and
- the same example plus the target answer's recursive type shape.

Each arm must produce 4–8 failures. Select the arm closest to six failures, preferring the
example-only arm on a tie. Otherwise stop without main calls. The V3 ceiling is 40 pilot plus 70
main case-runs, normally two requests each, with no automatic retries.

Machine authority is
`workforce-graph/data/predictive_validity/successor_2026-08-12-v3/frame.json`.

## Frozen pilot decision

Both scaffold arms produced 15 passes and 5 failures. The preregistered tie-break selected
`worked_example`, authorising the 70-case main run without further tuning. The pilot artifact is
`workforce-graph/data/predictive_validity/successor_2026-08-12-v3/pilot.json`; it records 80 requests,
96,428 input tokens, 5,158 output tokens, and estimated catalog-price cost $0.0418234.

## Frozen main decision

The selected `worked_example` arm produced 44 passes and 26 failures over the 70 frozen main cases,
so the instrument-range gate passed. The frozen main artifact is
`workforce-graph/data/predictive_validity/successor_2026-08-12-v3/main.json`.

The locked five-fold comparison returned difficulty-only log loss 0.436257 and
difficulty-plus-votes log loss 0.519719, an improvement of -0.083462. Under 1,999
category-blocked joint vote permutations, 1,952 permuted improvements met or exceeded the observed
one; the one-sided p-value is 0.9765. The frozen analysis artifact therefore records
`NO_DETECTED_INCREMENTAL_ASSOCIATION`.

This decision means only that the preregistered vote doses did not add predictive value for
agent-plus-worked-example deterministic conformance in this exact synthetic read-only harness.
Failures were concentrated in four categories with both outcomes, reducing realized
within-category sensitivity. It is not evidence that no relationship exists, and it does not
measure holistic mission success, GUI/OS operation, production performance, workforce share, or
isolated model capability.
